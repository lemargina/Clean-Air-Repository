# План и критерии за завършеност

Основен документ: `Clean Air Finder Bulgaria - prompt for codex.txt`. Работа локално, без Git, по последната инструкция на възложителя.

1. **Източници**: проверка на live JSON, CSV в дневни и месечни архиви, наличност за година, лицензи и география. Доказателства: `DATA-SOURCES.md`, локални HTTP отговори в `storage/research`.
2. **Архитектура**: PostgreSQL, immutable geographic snapshot на всяко измерване, completeness правила, ежедневни агрегати. Проверка: миграции на истински PostgreSQL и DST тестове.
3. **Backend**: валидация, API и локално класиране. Проверка: feature тестове, забранени непредвидени HTTP заявки.
4. **Събиране**: live, потоков CSV/ZIP backfill, retries, locks, checkpoints. Проверка: реален live импорт, архивна извадка, тест за прекъсване/продължаване.
5. **Агрегации**: sensor-hour → sensor-day → city-day → city-period. Проверка: покритие, равни тегла, равенства, повторно преизчисляване.
6. **Интерфейс**: Blade, календар, класиране, недостатъчна история, методология. Проверка: HTTP през nginx и feature тестове.
7. **Експлоатация**: Compose, scheduler, queue, архив/restore, Prometheus/Grafana. Проверка: стартиране на стек, healthchecks, metrics scrape, round trip на архив.
8. **Валидация**: автоматизирани тестове, synthetic benchmarks в отделна база, реален произход, финален доклад.

Техническото изпълнение не е равнозначно на завършен 12-месечен импорт. Този критерий остава отворен, докато всички източникови файлове не се обработят и локалното покритие не се провери. Изпълнените проверки и ограниченията са във `FINAL-REPORT.md`.
